# NuvoUI is now WovenUI

NuvoUI has been renamed to **WovenUI**. Same framework, same team, new name.

- Repository: [github.com/WovenUI/core](https://github.com/WovenUI/core)
- Website and docs: [wovenui.com](https://wovenui.com)
- npm: [`@wovenui/core`](https://www.npmjs.com/package/@wovenui/core)

Links to `NuvoUI/core` redirect to the new repository automatically.
NuvoUI 1.x stays available through the tags of that repository.
